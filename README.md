# 📊 Task 3: Marketing Campaign & Funnel Analysis (A/B Testing)

## 📌 Project Overview
This project evaluates performance metrics for two digital marketing strategies (**Control Campaign** vs. **Test Campaign**) to identify funnel drop-off points, analyze cost efficiency, and deliver data-driven recommendations for marketing ROI optimization.

Completed as part of **Task 3** for the **Future Interns Data Analytics Internship**.

---

## 🛠️ Tools & Technologies
- **Business Intelligence:** Power BI Desktop
- **Data Transformation:** Power Query
- **Data Modeling & Analytics:** DAX (Data Analysis Expressions)
- **Datasets:** A/B Testing Data (`control_group.csv` & `test_group.csv`)

---

## 📈 Key Insights & Recommendations

### 1. Control Campaign (Maximum Bidding Strategy)
- **Cost Efficiency:** Lower Cost Per Purchase (**$4.53 vs $4.92**).
- **High Intent:** Stronger mid-funnel engagement with a **67% Add-to-Cart rate**.
- **Best For:** Profitable retargeting and maximizing return on spend.

### 2. Test Campaign (Average Bidding Strategy)
- **Higher Scale:** Generated more total purchases (**15,637**) and top-of-funnel reach.
- **Conversion Performance:** Higher **Overall Conversion Rate (0.7% vs 0.5%)**.
- **Best For:** Rapid customer acquisition and scaling top-of-funnel traffic.
